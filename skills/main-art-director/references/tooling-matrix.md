### Grounded Multi-Agent Architecture & MCP Tooling Matrix

Before deploying the five `SKILL.md` files, here is how this system grounds its tool schemas across your three target runtimes and current MCP/CLI releases:

* **Triple-Runtime Compatibility**: Each skill uses standard Agent Skills YAML frontmatter (`name`, `description`) compatible with **Personalized Gemini**, **Google Antigravity IDE** (`~/.gemini/antigravity/skills/<skill-name>/SKILL.md` with Agent Manager and Chrome visual verification), and **AWS Kiro Crew** (`.kiro/skills/<skill-name>/SKILL.md` paired with `.kiro/specs/` `requirements.md`, `design.md`, and `tasks.md` spec-driven hooks).
* **Figma MCP (`https://mcp.figma.com/mcp` & `http://127.0.0.1:3845/mcp`)**: Wires official read tools (`get_design_context`, `get_metadata`, `get_variable_defs`, `get_screenshot`, `get_motion_context`, `download_assets`, `export_video`) and remote canvas-write tools (`use_figma`, `generate_figma_design`).
* **Dreamina CLI (`dreamina` & `dreamina-canvas`)**: Separates safe read-only operations (`user_credit`, `query_result`, `list_task`, `-h`) from guarded credit-consuming generators (`text2image`, `image2image`, `image_upscale`, `image2video`, `frames2video`, `multiframe2video`, `multimodal2video`) supporting Seedream and `Seedance 2.5` while preserving `submit_id` state and Dreamina 2.0 Canvas timeline exports.
* **Adobe Creative Cloud Dual-Bridge Architecture**: Uses current local UXP/CEP/ExtendScript MCP servers—`mikechambers/adb-mcp`, `matrayu/adobe-mcp`, and `photoshop-mcp-imt` for Photoshop 28.0 (including `Relight`, `Generative Restyle`, `Remove Ambient Effect Only`, and Topaz `Wonder 4`); `kumoproductions/mcp-aftereffects` and `Dakkshin/after-effects-mcp` for After Effects; and independent local Premiere Pro MCP servers (`import_fcp_xml`, `ripple_remove_timeline_ranges`, `trim_clip_by_frames`)—while enforcing non-destructive native file contracts ready for **Adobe’s Official Local MCP integrations** (previewed at Adobe MAX on November 10, 2026 for early 2027 private beta).
* **HyperFrames & Remotion**: Integrates `heygen-com/hyperframes` deterministic HTML/paused-GSAP CLI commands (`init`, `lint`, `check`, `snapshot`, `timeline --json`, `audio`, `beats`, `transcribe`, `render`, `clean`) alongside official `remotion-dev/skills` (`/remotion-best-practices`, `/remotion-markup`, `/remotion-render`) and Remotion v4 Studio WebMCP.
* **DaVinci Resolve Studio 21 MCP (`samuelgursky/davinci-resolve-mcp` v5.2.x)**: Maps Resolve Studio 21 scripting (`Preferences > General > External scripting using > Local`) across `resolve`, `project`, `media_pool`, transition-safe `timeline_item` (`timeline_item_id` via `GetUniqueId()`), `graph`/`drx` (`ApplyGradeFromDRX`), `fairlight`, `render`, and offline `.drp`/`.drt`/`.drx` tools.
* **Blender MCP (`ahujasid/mcp-for-blender` v1.9.4+)**: Drives live Blender sessions over TCP `localhost:9876` via `get_scene_info`, `get_object_info`, `look` / `get_viewport_screenshot`, atomic `execute_blender_code`, `bpy_api_lookup`, `describe_node_type`, and PolyHaven/Sketchfab/Hyper3D/Hunyuan3D integrations.
